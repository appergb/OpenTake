# OpenTake 1.0.0-beta.1

发布日期：2026-08-01（Asia/Shanghai）

## Beta 目标

提供一个可安装、可回滚、具备完整本地剪辑闭环的首个 Beta，让实际用户在 Apple Silicon
macOS 上完成工程创建、素材导入、多轨编辑、预览、保存重开与交付导出，并能按需使用
Agent、本地 AI、Motion Canvas 与 BYOK 生成能力。

## 候选包验收顺序

1. Home / 工程生命周期与恢复。
2. 素材库、文件夹、收藏、缩略图、波形、代理与重链接。
3. 时间线选择、拖放、裁剪、分割、复制、链接、吸附、撤销/重做与嵌套序列。
4. 预览播放、seek、scrub、A/V 同步、画布 Transform/Crop/Mask 与关键帧。
5. 文本/字幕、转写、翻译、SRT/VTT 与样式。
6. 特效、调色、LUT、HSL、色彩匹配、蒙版、转场、防抖、补帧与智能擦除。
7. 音频响度、降噪、声部分离、试听、独立落轨与导出。
8. Agent/MCP、官方 Codex CLI / ChatGPT 登录、Codex Agent 实际编辑、口播清理、图文成片、
   本地/云生成失败边界。
9. Motion Canvas、原生 Chromium fallback、保存重开与最终导出。
10. 数字人/音色克隆的无凭据拒绝、同意/成本控件、取消/重试、试听与撤销界面。
11. 最终 H.264/H.265/ProRes、字幕和交换格式导出，重启后重新打开工程。

每一项必须在同一候选包上按顺序执行；代码测试不能替代 GUI 观察，GUI 观察也不能替代
媒体 probe、项目重开或导出文件检查。

## 外部门槛

- `fal`、ElevenLabs、OpenAI、Anthropic 凭据当前环境均未配置。未经用户提供凭据和明确
  费用授权，不执行真实付费请求；确定性 provider fixture 已覆盖协议、原子性与持久化。
- 官方 Codex CLI 登录是 Agent 的独立可选入口：OpenTake 只执行 `codex login status`、
  `codex login`、`codex logout` 与受限的 `codex exec`，不读取、复制或持久化 ChatGPT 凭据。
  候选包必须验证登录态显示和一次真实 MCP 编辑；该调用受用户 ChatGPT/Codex 账户条款约束。
- 当前钥匙串只有 Apple Development 身份，没有 Developer ID Application 身份，也没有
  Apple 公证凭据。本地 Beta 可以构建和使用，但不宣称已签名/公证。
- Windows 安装器由 GitHub Actions 的精确提交 SHA 工作流构建。原生 Windows UI 人工烟测
  需要 Windows 交互环境，不能由本机 macOS 伪造。
- Unix 原子“创建目录并同时取得该创建对象身份”的可移植原语不存在；安全文件系统在该
  单一生产操作上严格拒绝，普通工程目录创建使用已审计的上层完整包发布流程。

## 回滚

- 本 Beta 使用独立 prerelease 标签 `v1.0.0-beta.1`，不会移动正式版标签。
- GitHub Release 保留候选包 SHA-256；发生阻断问题时撤下 prerelease 资产并回退到前一个
  已验证提交，不改写用户工程。
- 工程格式保持向后兼容；新增字段使用默认值。回滚前先复制 `.opentake` 包，避免旧程序
  忽略新功能字段后继续保存造成语义丢失。
