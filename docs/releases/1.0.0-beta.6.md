# OpenTake 1.0.0-beta.6

候选日期：2026-09-06（Asia/Shanghai）。更新已提交至 [GitHub PR #249](https://github.com/appergb/OpenTake/pull/249)。当前为未发布候选，最终发布状态由本页及 GitHub Release 回读证据更新。

## Beta 目标

在已公开 Beta 5 的基础上，收敛桌面剪辑、预览、导出与文档，并交付官方宣传视频。历史 Beta 1–5 已发布，这次使用新的 `v1.0.0-beta.6`，不复用旧 tag，也不将 Beta 称为稳定 1.0。

## 本次变化

- 小屏窗口根据显示器工作区裁剪，标准/紧凑布局、分栏、设置和 Home 内容适配可用空间。
- 多素材预览标签支持切换、关闭回退及旧工程状态归一；媒体面板支持文件夹、平铺、分组三种组织方式。
- 修正 macOS 文件导入选择器；JSON Lottie 与 `.lottie` 容器经实际动画校验后导入，时间线通过原生合成播放。
- 时间线增加 Shift 标尺范围与边缘拖动、吸附和取消回滚；Option trim 只影响主选片段；分割/修剪遵守选区条件；同步刷新时将播放头约束到有效长度。
- 变速/倒放与合成属性组合走原生 RenderPlan 时间映射；缺失媒体返回明确错误；修正 WebKit 超过 0 dB 增益与全轨音频解码。
- Motion Studio 支持透明发布、透明媒体持久化和后续编辑，导出提供 ProRes 4444 alpha。
- 导出通过后台blocking task执行，界面进度和取消保持响应；worker持有owned导出lease，提前取消在任何输出初始化前返回。转写沿已有有界推理队列运行。
- 普通导出失败清理尊重输出文件身份，外部取消贯通到进程与编码；进度订阅建立期间的取消意图不丢失。
- 文本面板接入既有文本创建/Inspector，效果预设支持链接视频/音频选区中的视频片段并保留单步撤销。
- 贴纸面板支持当前工程图片/Lottie导入、预览、选择和落轨；同工程切换标签保留落轨处理中状态及失败提示。
- 语义搜索使用固定revision、字节数和SHA-256的公开SigLIP2 ONNX资产，正确处理tokenizer、模型I/O与归一化，保留离线安装。新v2索引与旧缓存隔离，模型损坏提供可识别的修复状态，重任务移出界面线程并复用既有推理队列，排队超时明确提示且保留其他结果组。Windows通过已有锁定Tract引擎绑定固定模型输入，避免旧适配层不支持的接口和动态shape问题。
- Agent 文件夹批量操作保持单一事务，按帧移动链接片段时同步伙伴。
- PCM显式区间在重采样后按目标帧数裁剪；完整音轨保留原始解码结果，并为元数据未计入的padding提供最多一秒的有界缓冲余量，仍执行超限和取消保护。
- 测试存储按文件隔离，消除 Node 原生 localStorage 跨测试语言污染；按当前 Rust 工具链修复 lint。
- Web 锁文件升级 `nanoid` 至 3.3.18；Motion Canvas 的 `@xmldom/xmldom` 固定到 0.9.12；保留锁定安装、依赖审计及内嵌 runner 可复现门禁。

语义搜索已有macOS原生Rust真实模型/图文排名证据，贴纸已有Web交互证据；当前候选的完整桌面及Windows后端验收仍在执行。只在匹配证据产生后升级状态，第三方服务与上游私有云账户边界见能力清单。

## GitHub 自动发布流程

正常 tag push 的 product source SHA 与 release tooling SHA 必须相同，并等于当前远端 `main` HEAD。Cargo/Tauri/Web 版本必须为 `1.0.0-beta.6`，Windows WiX 版本为 `1.0.0.6`，公开类型为 prerelease。工作流只消费已存在的不可变 tag，不创建、移动或删除 tag。

validate、quality、macOS ARM64、Windows x64 全部成功后，publish 才能生成并校验十七项发布资产：平台安装器、updater 包与签名、receipt、attestation、tag-specific manifest 和 `SHA256SUMS`。上传前、公开前与下载回读均检查源 commit、文件数量、大小、校验值和签名。旧公开 Release 不能覆写。

`workflow_dispatch` 恢复仅保留历史 Beta 4 的事故链，不能作为 Beta 6 的任意恢复入口。它要求 `failed_run_id`、`failed_run_id=31412976593` 与 `failed_recovery_run_id=31441693191`，原不可变 tag SHA 为 `2c4efdff9d2587c90cbcac0919f9d1d333d67d6a`，前驱 tooling 为 `924bc1102a9343e14c3beea2a3622b5d92ebff13`。校验必须证明 source → `924bc110…` 与 `924bc110…` → 当前远端 `main`，当前 tooling 绑定到 `github.workflow_sha`。

恢复时公开 release notes 从 exact tooling commit 读取并记录 notes commit。REST `target_commitish` 只做非空 schema 校验，实际源由远端 tag peel 与 GraphQL `tagCommit.oid` 共同核对。

## 平台与服务边界

- macOS 应用采用 ad-hoc 签名，未获得 Developer ID 签名或公证；Windows 安装器未使用 Authenticode。
- updater 私钥与密码只由 GitHub Actions secrets 提供，缺失则 gate 失败；不进入源码、日志或资产。
- Windows 安装/文件系统/媒体门槛必须有 Windows exact-SHA 证据；macOS GUI 不能替代。
- 云生成、翻译、数字人及音色克隆需要相应 provider、凭据和授权；不以模拟测试宣称真实付费请求成功。
- 上游 Palmier 私有账户后台不在此开源仓库内，OpenTake 使用已有本地/BYOK/官方 Codex 接入边界。

## 回滚

保留 `v1.0.0-beta.5` tag、资产与历史审计；回退前复制 `.opentake` 工程。Beta 6 若公开后出现回归，保留该 tag 与资产，下一修复使用更高版本重新验证发布。
