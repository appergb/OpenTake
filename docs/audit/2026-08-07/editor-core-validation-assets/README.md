# Editor Core Validation Assets

本目录保存 `editor-core-validation.md` 的 GUI、生成缓存、fresh GUI 导出、独立子审计与可重开工程证据。

## 关键证据

- `fresh-gui-ledger.md`：安装包身份、操作顺序、稳定等待、重开、播放、导出和诊断边界。
- `resource-ui-static.md`：独立子 Agent 的资源有界性与 UI/WCAG 审计。
- `competitor-official-sources.md`：独立子 Agent 基于 19 个厂商官方页面的竞品差异核验。
- `04`–`13`：2026-08-08 fresh 安装包 GUI 截图。
- `05-generated-thumb-valid.png`、`06-generated-preview-valid.png`：GUI 破图/黑预览同时存在的有效缓存文件。
- `gui-validation.opentake/`：fresh GUI 保存并重开的 4K60 工程。
- `gui-export-720p.mp4`、`14-gui-export-frame-2s.png`：fresh GUI 导出与抽帧。

## 格式提醒

`01`–`03` 虽以 `.png` 命名，内容实际是 JFIF JPEG；`04`–`13` 为 JPEG，`05`、`06`、`14` 为真实 PNG。主报告已按真实格式解释，避免把扩展名当证据。
