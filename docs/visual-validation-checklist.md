# OpenTake 视觉验收 Checklist

## 1. 预览渲染
- [ ] 暂停态：GPU composite PNG 正确显示
- [ ] 播放态：`<video>` 元素流畅播放
- [ ] clip 边界切换无闪烁/卡顿
- [ ] 多轨道叠加正确（上层覆盖下层）

## 2. 音频播放
- [ ] 单轨道音频正常播放
- [ ] 多轨道音频混音正确
- [ ] Mute 按钮静音生效
- [ ] Solo 按钮独奏生效（其他轨道静音）
- [ ] 音量滑块控制生效

## 3. CSP 安全策略
- [ ] 资产缩略图加载正常（asset: 协议）
- [ ] composite PNG 显示正常（data: URI）
- [ ] MJPEG 预览流加载正常（http://127.0.0.1:*）
- [ ] 字体加载正常
- [ ] inline style 渲染正常
- [ ] 无浏览器控制台 CSP 报错

## 4. 时间线交互
- [ ] 拖拽 clip 移动正常
- [ ] 拖拽 clip 边缘 trim 正常
- [ ] 播放头拖拽定位正常
- [ ] Track solo/mute/hide 按钮响应正常
- [ ] 缩放（水平/垂直）正常

## 5. Inspector / 关键帧
- [ ] Clip 属性编辑生效（位置/缩放/旋转/不透明度/裁剪）
- [ ] 关键帧面板展开/收起正常
- [ ] 关键帧钻石拖拽定位正常
- [ ] Stamp/Clear 按钮正常
- [ ] 右键插值菜单正常

## 6. 媒体库
- [ ] 素材导入正常（文件/文件夹）
- [ ] 素材网格显示正常（缩略图 + 文件名）
- [ ] 拖拽素材到时间线正常
- [ ] 全局素材库分类切换正常
- [ ] 收藏/取消收藏正常
- [ ] 从全局库导入到项目正常

## 7. 播放性能
- [ ] 30fps 播放稳定（无掉帧）
- [ ] GPU 读回不阻塞 UI 线程
- [ ] 长视频 seek 无明显延迟
- [ ] 50 轨道项目仍可操作（性能基线）
